## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **ASI Plugin Support** | Load ASI mods directly without modifying game files |
| **Clean Install** | All mod files stay separate from base game archives |
| **Load Order** | Control the order mods initialize to resolve conflicts |
| **Easy Removal** | Disable any mod instantly by removing a single file |
